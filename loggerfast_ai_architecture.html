LoggerFast AI Integration

AI-assisted industrial site configuration — Engineer describes the site, Hermes configures everything

How It Works

  • • Engineer describes their site in plain language
  • • AI understands the setup and looks up device knowledge
  • • AI proposes a complete configuration plan
  • • Engineer reviews and approves before anything changes
  • • AI executes: creates gateways, devices, schemas, mappings, jobs
  • • AI validates every reading against 3 layers of checks

Smart Validation

  • • Layer 1: Physical rules — is this voltage possible?
  • • Layer 2: Neural network — does this reading pattern look right?
  • • Layer 3: Predictive — is this device drifting from its baseline?
  • • Catches reversed CTs, wrong byte order, misidentified meters
  • • Confidence score tells the engineer how trustworthy readings are
  • • No cloud needed — all inference runs locally

Gets Smarter Over Time

  • • Learns reusable procedures from successful configurations
  • • Next time someone sets up PM5110s, it's faster
  • • Skills are portable — export from one site, import at another
  • • Knowledge base grows as new meter types are encountered
  • • Anomaly detection improves with every verified installation
  • • Fully offline — works on air-gapped industrial sites
