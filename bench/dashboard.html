Key takeaway: The after-optimization run handles 12.5% more tables (270 vs 240) while being 25–32x faster. The 8-job scenario achieved the best result: 32.4x speedup (308.6ms → 9.5ms). Loop P95 dropped from hundreds of milliseconds to single digits, leaving >970ms of headroom in each 1000ms interval.

Throughput (reads/sec) vs Table Count

Overrun % vs Table Count

Percentage of loops exceeding the 1000ms interval. 0% = all loops fit within budget.

Memory (RSS MB) vs Table Count

At 250 tables, Rust delivers 250.5 reads/s vs Python's 152.9 reads/s (1.6x). Memory: Rust uses 10–20x less RAM at every table count.
